QUY TRÌNH CHATGPT WEB ↔ CODEX TRÊN WINDOWS

1. Tôi trao đổi vấn đề/ý tưởng trong ChatGPT Project Hermes Clip.
2. ChatGPT dựa vào bối cảnh, ảnh và source snapshot để gợi ý; chỉ rõ bằng chứng hoặc giả thuyết.
3. Khi tôi chọn hướng, ChatGPT viết prompt theo 05-MAU-PROMPT-CHO-CODEX.txt.
4. Tôi dán prompt vào Codex, dùng cấu hình Astra Ultra tôi chọn. Chỉ một agent. Codex đọc source mới nhất, triển khai và kiểm tra trên Windows.
5. Codex trả báo cáo ngắn dưới đây. Tôi mang về ChatGPT, kèm file source đã sửa/ảnh mới khi cần.
6. ChatGPT cập nhật trạng thái; không tiếp tục viện dẫn source cũ như thể còn đúng. Những phần chưa có cập nhật giữ nguyên mức chứng minh cũ.
