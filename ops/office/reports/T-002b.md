Unknown media không xuất/gắn take kể cả gọi API trực tiếp; unknown text không gọi Codex; scope sản phẩm khác vẫn chạy được bằng runner giả và ghi receipt codex.

Manual dùng **MP4/PNG thật tạo bằng FFmpeg** trong thư mục tạm: cấu trúc prompt-pack, ảnh/checksum, đúng mã/sai mã/tỷ lệ ngang, duplicate/restart, watcher, receipt mất phản hồi. Luồng media Muse dùng adapter và kiểm file giả để kiểm pause/continuation; không gọi Muse hay lấy file từ dịch vụ thật.

69 fail ở lượt desktop từng file gồm subprocess/FFmpeg/Chrome bị chặn; có lỗi phụ từ fixture (ví dụ page.screenshot không có) sau khi công cụ không khởi chạy. Không giảm assertion và không kết luận mọi test chức năng đã đạt. Ba test chạy **file Codex giả** vẫn fail ở spawn EPERM; các test process events/service và hai test đối soát đạt. Lượt chạy tất cả desktop chung một process bị before-hook Chrome làm dây chuyền, chỉ giữ log T-002b-desktop-direct.log để chẩn đoán; dùng lượt từng file để đánh giá giới hạn rõ hơn.

## Chưa kiểm / blocker

- Chưa đạt full suite xanh và chưa có ảnh thật ở 1366/1920 cho ba màn/hai trạng thái. Không có PNG để đính, không dùng ảnh thay thế. Script sẵn nhưng phần tương tác/bố cục chưa chạy được trong sandbox.
- Chưa kiểm Electron/IPC thật, DPI Windows, đồng bộ công tắc trong bản cài thật, profile/session/quota thật, submit/download Muse thật. Fixture không chứng minh tài khoản hoạt động.
- Chưa chạy Codex CLI thật; chưa xác minh đăng nhập/hạn mức/cờ native của máy. Không dùng API trả phí.
- Chưa thử file tải thật từ Flow/Gemini/Grok. Giữ các giới hạn manual cũ: ảnh 8 MB/video 25 MB, không quét thư mục con, sai tỷ lệ cảnh báo; duyệt/ghép vẫn áp dụng kiểm thông số.
- Chưa build vào desktop/local-dist hay sửa dữ liệu thật. Không commit; boss review và commit/build thật sau.

## Cách chạy tiếp

Ngoài sandbox có quyền tạo subprocess và Chrome IPC, tại checkout hiện tại:

~~~powershell
pnpm typecheck
pnpm test
pnpm test:api
pnpm test:desktop
$env:HERMES_LOCAL_BUILD_DIR = "$PWD/outputs/T-002b-build"
pnpm local:build
$env:HERMES_ARTIFACTS = 'D:/hermes-wt/artifacts/T-002b'
node scripts/check-muse-routing-ui.mjs
~~~

Chạy lại bộ tập trung và test file Codex giả nếu cần; không cần Codex/Muse thật để nghiệm thu fixture. Script dự kiến tạo T-002b-<tao-video|tai-khoan-muse|cai-dat>-<1366|1920>-<tam-dung|bat>.png và T-002b-ui.json. Chỉ đánh dấu ảnh đạt sau khi script thành công và xem ảnh.
