## Thay đổi và hợp đồng

- Client thuần inject fetch, không dependency mới: identity, create Reels container, upload bytes resumable có cờ, status_code, publish, media, insights, comments cursor, content_publishing_limit. Host/version/field đều có TODO đối chiếu Meta hiện hành; không request ngoài trong đêm. Mặc định tắt, không version mặc định; `v99.0` chỉ là fixture.
- `apiMode` theo hồ sơ, mặc định browser. Token qua secret encrypt/decrypt dùng cùng safeStorage của mật khẩu proxy; không trả token/ciphertext qua status, không đưa raw response/URL/error vào log. Giữ/xóa token, đổi mode và kiểm danh tính có test; ID từ Instagram Login không dùng thay ID browser.
- Snapshot/fingerprint/revision/checksum cũ giữ nguyên. Receipt ghi **trước create**, lưu container ID trước upload, lưu media ID trước đọc proof. Một POST publish, không retry/upload lại/tạo container mới khi chưa rõ. Lỗi container, timeout ở mọi bước, restart đều giữ cần đối soát. Reconcile chỉ đọc; mất publish response chưa có media ID thì giữ cần đối soát, không đoán từ caption. Required AI label bị chặn trước container vì API chưa xác minh nhãn.
- API metrics dùng `social_metric` hiện có, source `api`, lifetime, thời điểm/URL/account/handle; reach riêng, missing/invalid giữ null, zero giữ 0. API nội bộ kiểm account/URL như browser. Bài browser cũ tra media ID bằng permalink trên tối đa 5 trang media. Đổi ngược API → browser dùng ID browser đã xác minh, không dùng ID API. Comments client phân trang có chặn cursor lặp/host chuyển hướng; chưa có private reply hoặc UI đọc comments tự động.
- Giữ status `published_browser` để các reader cũ tiếp tục nhận bài đã đăng qua app, thêm `publishSource` optional và proof `source: api`. UI hiển thị “Đã đăng qua app”; form nhỏ giữ font/theme/bố cục sẵn có. Nút kiểm/đăng API khóa khi cờ tắt; chỉ bấm lưu cấu hình không gọi Meta.
