## Dùng tiếp

Chạy các lệnh npm như trước. Khi chỉ cần một file với một build dùng chung, dùng `node scripts/run-source-tests.mjs desktop desktop/test/research-runner.test.mjs` hoặc `node scripts/run-source-tests.mjs api tests/operations-api.test.mjs` từ root. Đường dẫn test luôn tính theo thư mục gọi lệnh.

Khi chạy thẳng `node --test <file>`, helper tự build một lần cho mỗi tiến trình test và dọn khi tiến trình kết thúc. Không cần `--import` hook. Test mới import domain/UI bằng `importModule('lib/lab/operations.ts')` hoặc `importModule('components/lab/research-sources.tsx')`; API fixture dùng `importApiModule()`. Entry mới chưa thuộc đồ thị dependency cần được thêm vào danh sách entry của helper.
